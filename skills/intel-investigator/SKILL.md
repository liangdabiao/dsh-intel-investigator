# A股情报调查员

深度情报调查与分析方法论：帮你快速完成公司研究、竞品对比、事件追踪、背景核实和信息验证，输出结构化调查报告。核心聚焦A股市场，同时覆盖竞品/舆情/人物/信息验证四类通用调查。

## 工作流程（六步）

1. **需求确认**：明确调查目标、范围、时间约束（目标模糊先请用户具体化）
2. **策略编排**：`intel_investigate(action="plan", mode, subject)` 生成三轮搜索执行清单
3. **广域扫描**（第1轮）：广泛关键词搜索，建立全景认知
4. **深度挖掘**（第2轮）：细分关键词，挖掘真实反馈
5. **交叉验证**（第3轮）：多源比对，确认关键数据可信度
6. **报告生成**：按模板输出结构化调查报告，`intel_investigate(action="save", reportMd=…)` 存证

## 调查模式速查

| 模式（mode） | 调查目标 |
|------|---------|
| stock（A股情报调查） | A股公司基本面、行业赛道、概念热点、资金动态、公告事件 |
| competitor（竞品情报调查） | 分析竞品产品、市场策略、用户口碑 |
| event（舆情事件调查） | 热点事件追踪、舆论走向分析、危机监测 |
| person（人物背景调查） | 商务合作前的背景调查、行业人物了解 |
| verify（信息交叉验证） | 验证信息真实性、对比不同来源说法 |

五种模式的详细策略编排见 [investigation-modes.md](references/investigation-modes.md)；引擎选择决策树与高级搜索法（反向搜索/时间轴/地域对比/垂直深耕/证据链构建）见 [engine-strategy.md](references/engine-strategy.md)；完整执行流程与可信度判定见 [core_workflow.md](references/core_workflow.md)；五种报告完整模板见 [investigation-templates.md](references/investigation-templates.md)。

## 可信度标注规范

| 标识 | 含义 | 判定标准 |
|------|------|---------|
| ✅ 已确认 | 信息可靠 | 2+个独立来源一致 |
| ⚠️ 待确认 | 有争议 | 来源说法矛盾 |
| ❌ 已否定 | 信息不实 | 权威信源反驳 |
| 🔍 单一来源 | 仅1个来源 | 需进一步验证 |

### 信息源分级（ABCD）

| 级别 | 类型 | 示例 |
|------|------|------|
| A级 | 官方/政府/权威媒体 | gov.cn, reuters.com, xinhuanet.com, cninfo.com.cn(巨潮), sse.com.cn(上交所), szse.cn(深交所) |
| B级 | 行业媒体/专业平台 | 36kr, techcrunch.com, eastmoney.com(东方财富), 10jqka.com.cn(同花顺), stcn.com(证券时报) |
| C级 | 社交媒体/自媒体 | weibo, zhihu, reddit, xueqiu.com(雪球) |
| D级 | 匿名/未验证来源 | 贴吧, 4chan, 股吧匿名帖 |

关键财务/事件数据必须 A/B 级信源交叉验证后才可标 ✅；C/D 级信源只能给 ⚠️ 或 🔍。

## 报告纪律

- 每条关键发现必须带**来源**（内联链接优先）与**可信度标注**。
- 所有数值来自真实检索结果，严禁估算编造；没查到就写"未检索到公开数据"。
- 没有搜索工具时如实告知用户，只做基于用户提供材料的分析并标注"未联网核实"。
- 报告写完必须 `intel_investigate(action="save")` 存证；存证状态（已存证平台/仅本地）如实转述。
- RedFox 存证接口对正文限 2000 字符：超长报告会自动改传结构化摘要（关键结论 + 关键信息验证 + 风险评估），全文只保留在本地档案。这种情况要说"平台存证为摘要版"，不能说"全文已存证"。

## 面板与档案

- 侧栏「A股情报调查员」面板是调查档案室：全部报告按模式归档、可信度统计、报告查看（可打印/导 PDF）、平台存证状态与重新上传。
- 用户要补传/重传报告时引导到面板档案详情页点「重新上传」。
